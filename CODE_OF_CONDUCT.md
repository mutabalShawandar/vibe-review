# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcoming, and constructive. Harassment, discrimination, and personal attacks are not tolerated.

## Reporting
Report unacceptable behavior to the maintainer, [@mutabalShawandar](https://github.com/mutabalShawandar), by the contact method on their GitHub profile. Please do not report it in a public issue or pull request. Reports are handled confidentially, and the reporter's identity is not shared.

## Enforcement
Maintainers may remove, edit, or reject comments, commits, issues, and other contributions that violate this code, and may temporarily or permanently ban contributors for behavior they deem inappropriate.
